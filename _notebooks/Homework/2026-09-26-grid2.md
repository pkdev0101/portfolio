## Popcorn Hack 1: Fix the Beaker Row

Replace the inline style and made-up `box` class with OCS grid classes.

```html
%%html
<!-- UI_RUNNER: Popcorn Hack 1 - Fix the Beaker Row -->
<div class="ocs__grid ocs__grid--standard">
  <div class="ocs__grid-cell">Beaker 1: 12.4 mL</div>
  <div class="ocs__grid-cell">Beaker 2: 11.8 mL</div>
  <div class="ocs__grid-cell">Beaker 3: 13.1 mL</div>
</div>
```

**Result:** One `ocs__grid`, one standard variant, three `ocs__grid-cell` boxes. No `style` attribute and no `box` class left.

## Popcorn Hack 2: Size the Beakers with `fr`

Put all 4 beakers in one row and make the Control Beaker twice as wide.

```html
%%html
<!-- UI_RUNNER: Popcorn Hack 2 - Size the Beakers with fr -->
<div class="ocs__grid" style="grid-template-columns: 1fr 1fr 1fr 2fr;">
  <div class="ocs__grid-cell">Beaker A</div>
  <div class="ocs__grid-cell">Beaker B</div>
  <div class="ocs__grid-cell">Beaker C</div>
  <div class="ocs__grid-cell">Control Beaker</div>
</div>
```

**fr values used:** `1fr 1fr 1fr 2fr`  
(4 values → 4 boxes in one row; the last `2fr` makes Control twice as wide)

## Homework Hack

Fix both grids using only OCS classes. Goal: every checklist line shows **PASS**.

```html
%%html
<!-- UI_RUNNER: Homework - Fix both grids -->

<!-- Grid 1: standard grid of beaker readings -->
<div class="ocs__card">
  <div class="ocs__grid ocs__grid--standard">
    <div class="ocs__grid-cell ocs__grid-cell--header">Trial 3 Beaker Readings</div>
    <div class="ocs__grid-cell">Beaker 1: 12.4 mL</div>
    <div class="ocs__grid-cell">Beaker 2: 11.8 mL</div>
    <div class="ocs__grid-cell ocs__grid-cell--accent">Beaker 3: 13.1 mL (outlier)</div>
  </div>
</div>

<!-- Grid 2: calculator keypad -->
<div class="ocs__card">
  <div class="ocs__grid ocs__grid--calculator">
    <div class="ocs__grid-cell">7</div>
    <div class="ocs__grid-cell">8</div>
    <div class="ocs__grid-cell">9</div>
    <div class="ocs__grid-cell">/</div>
    <div class="ocs__grid-cell">4</div>
    <div class="ocs__grid-cell">5</div>
    <div class="ocs__grid-cell">6</div>
    <div class="ocs__grid-cell">*</div>
    <div class="ocs__grid-cell">1</div>
    <div class="ocs__grid-cell">2</div>
    <div class="ocs__grid-cell">3</div>
    <div class="ocs__grid-cell">-</div>
    <div class="ocs__grid-cell">0</div>
    <div class="ocs__grid-cell">.</div>
    <div class="ocs__grid-cell ocs__grid-cell--accent">Avg</div>
    <div class="ocs__grid-cell">+</div>
  </div>
</div>
```

**Checklist (all PASS):**
- Both grids use `ocs__grid`, one variant, and `ocs__grid-cell` on every box
- Title uses `--header`
- Outlier beaker uses `--accent`
- Keypad uses `ocs__grid--calculator` with accent Avg key
- No inline styles or made-up classes
